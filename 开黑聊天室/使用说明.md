# 同频 · 开黑聊天室

Node.js 自带模块运行，无需 npm install。独立使用3443端口，不影响心晴网站的3000和管理后台的3190。

## 第一次启动（Windows 电脑）

1. 服务器与朋友的电脑均加入同一个 ZeroTier 网络并获得授权。
2. 在本项目文件夹打开 PowerShell 7，运行 `pwsh -File .\生成证书.ps1 -Address 你的ZeroTier虚拟IP`。证书不自动安装到任何设备，有效期180天。
3. 将 certs 文件夹里的“给朋友的证书.cer”通过可信方式交给朋友，并核对生成时打印的SHA256指纹。不要分享 server.pfx，它包含服务器私钥。
4. 你和朋友在 Windows 中双击 cer → 安装证书 → 当前用户 → 将所有证书放入下列存储 → 受信任的根证书颁发机构。此操作代表信任你自行生成的站点证书，只对核对过的证书进行操作。Chrome/Edge重启后再访问；其他浏览器的信任设置可能不同。卸载时在 certmgr.msc 的对应存储中删除这张 Squad Chat 证书。
5. 双击 start.cmd，保持窗口运行；打开 `https://你的ZeroTier虚拟IP:3443`。双方都使用这个地址，本机不要用 localhost 的链接邀请朋友。
6. 先登录或注册共用账号，再选择房间码加入；复制邀请链接发给朋友。点击“开启语音”，允许麦克风权限。两人必须都开启语音才会建立语音连接。

房间码相当于进入房间的凭证，请使用难猜的随机房间码，只分享给朋友。房间码区分大小写。聊天室必须登录；与心晴手账共用用户名、密码、昵称和账号状态。昵称在心晴个人中心修改；不同用户的显示昵称仍可能相同。

## 功能

- 最多8人/房间；实时文字、在线列表、语音、静音、关闭队友声音、切换麦克风、邀请链接、离开房间。
- 访问窗口显示时间、IP、请求路径和HTTP状态码，不记录聊天正文、房间码、会话凭证及语音。SSE长连接的访问记录会在连接关闭后出现。
- 不录音；文字只实时广播，刷新/重新加入不能找回历史；服务器停止后房间清空。
- 语音是WebRTC设备间连接，使用ZeroTier网络的直接候选地址，没有配置公共STUN/TURN。能否连接取决于双方浏览器与网络策略；文字能用不代表语音一定连通。大房间会增加每人的带宽，建议2～6人。
- 关闭网页后成员可能最多45秒才从名单移除。网络恢复后会尝试重连，若会话过期请重新加入。

## 排查

- HTTPS证书错误：确认网址中的IP与生成证书时一致，日期正确，证书在本机和朋友电脑上都受信任。仅跳过浏览器警告不能保证麦克风可用。ZeroTier IP变化或证书到期后需要重新生成、重新分发信任。
- 无法打开：确认服务器运行、双方ZeroTier已连接；必要时在Windows防火墙中添加限定ZeroTier来源的TCP3443入站规则。本项目不自动修改防火墙。
- 没声音：双方点击开启语音，允许麦克风，检查静音和系统输入设备；若显示恢复声音按钮请点击。建议先同机双标签页验证，再与朋友异机测试；戴耳机防回声。
- WebRTC失败：检查双方ZeroTier互通，以及防火墙对浏览器在ZeroTier接口的通信限制。无需把网站端口转发到公网。

本机开发预览（仅测试）：PowerShell 执行 `$env:CHAT_HTTP='1'; $env:HOST='127.0.0.1'; node server.cjs`，打开 http://localhost:3443。HTTP模式仅用于本机预览，朋友通过IP使用HTTP不能开启麦克风。

测试：`npm test`。当前需在真实的两台设备上进一步验证语音与ZeroTier路径。


## 共用账号登录（新增）

- 直接使用心晴手账已有用户名和密码；在聊天室注册的新账号也能登录心晴，无需重复注册。
- 共用账号目录：E:\ZeroTier One\data\accounts。没有迁移或覆盖已有账号、手账记录。
- 两站分别登录和退出；普通登录会话重启后失效，勾选自动登录可保持30天。聊天室HTTPS Cookie与心晴HTTP Cookie使用不同名称，互不覆盖。
- 心晴修改密码、管理后台停用账号或强制下线，会令两个网站的旧会话失效。聊天室会在下一次请求或最多约10秒的检查周期后移除成员并关闭语音。
- 聊天室仅提供注册、登录、会话和退出接口，不提供手账记录或个人资料读取接口。账号昵称在心晴个人中心修改。
- 依赖心晴项目中的 accounts.js、sessions.js 和 public/storage.js，因此保留 E:\ZeroTier One\心晴手账 源码；心晴网站服务本身不必同时运行。
- 已打开的聊天室服务必须重启才能启用：总启动窗口输入 s2 回车，再输入 2 回车；刷新浏览器。旧匿名房间会清空。
