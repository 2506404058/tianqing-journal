# 数据与隐私

本项目有三种运行方式：

- **本机版**：双击启动脚本或运行 npm start，只监听 127.0.0.1。心情、日程及备注自动保存到 Windows 当前用户的 `E:\ZeroTier One\data\desktop\records.json`，不放进代码仓库，不发送到云端。每次保存前保留上一版 records.json.bak；下次启动会自动读取文件。
- **公开网页版**：静态托管时仅存于访问者当前浏览器当前网站来源的 localStorage。不启用本机数据接口，不将记录发送到服务器或第三方。托管商仍可能处理常规访问日志。

- **ZeroTier账号版**：在分享服务中注册登录，每个账号独立保存于 `E:\ZeroTier One\data\accounts`。心情、日程及压缩图片发送到这台服务器，可在其他设备登录读取。账号服务不读取旧本机日记或自动迁移浏览器记录。服务器主人能读取服务器文件，记录没有端到端加密，详见 [LOGIN.md](LOGIN.md)。

本机版同一 Windows 用户下的浏览器共用本机记录，没有多账号隔离。访问本机数据需要当前服务会话，接口拒绝跨站写入，并检查记录版本以防多页面覆盖。它是单人本机程序，请勿修改为公网监听或把本机端口转发到公网。

本机数据没有额外加密，能访问该 Windows 用户文件的人可能读到记录。电脑文件损坏、重装系统或删除数据目录可能导致丢失，请定期手动导出到独立备份位置。上一版自动备份不能代替长期备份。

首次使用本机模式时，如果尚无文件记录，会自动迁移当前浏览器已有的记录，并保留浏览器副本。已有本机文件优先，不会拿浏览器旧数据自动覆盖它。旧版 data/records.json 已原样归档至服务器 backups/cleanup-*/archived/tianqing-project/data/records.json，仍可通过导入迁移一次。

网页版不同浏览器、设备和域名不自动同步；同一浏览器配置中的同一网站共用数据。隐私模式关闭或清理网站数据可能使网页版记录丢失，请先导出备份。

导入会校验格式，并确认替换当前模式的记录。请勿将个人 JSON 备份上传到公开仓库。.gitignore 不会清除已提交的内容；发布前请检查暂存区和历史记录。

图片在当前浏览器内压缩，随心情记录一起保存和导出。账号版会将它们保存在你选择的心晴服务器；静态版和本机版沿用原来的保存方式。不使用第三方图床。升级数据结构前保留永久迁移备份，详见 MIGRATION.md。


登录页可选择下次自动登录（30天），默认不勾选。勾选后浏览器保存HttpOnly登录Cookie，服务器的凭证摘要与到期信息保存在 E:\ZeroTier One\data\accounts\sessions；不保存明文密码。退出登录立即撤销该设备凭证，修改密码会使其他设备会话失效，详见 LOGIN.md。

本机版和ZeroTier账号版会在启动窗口显示访问时间（北京时间）、连接来源IP、请求方法、路径、响应状态码及耗时。仅记录路径，不记录查询参数、Cookie、密码或日记正文；来源IP取实际连接，不信任客户端自报的转发地址。日志沿用服务器E盘目录：账号版logs/server.log，本机版logs/desktop.log，单文件约5MB后轮换并保留上一份。整合启动菜单会给本窗口启动的服务日志加上项目名称；复用服务的日志仍在原启动窗口。
