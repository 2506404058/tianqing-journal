# 通过 ZeroTier 分享心晴手账

## 两种启动方式

- `启动心晴.cmd`：自己使用的本机版，默认 localhost:3177，自动读取个人记录文件。
- `启动ZeroTier分享.cmd`：给朋友使用的账号网页版，当前电脑使用本机配置的3000端口（无配置时默认3180），只绑定当前 ZeroTier IPv4，按账号独立保存记录，不读取或提供原本机日记文件。

分享脚本会自动寻找 ZeroTier 网卡。如果加入多个网络，可先设置 `TIANQING_SHARE_HOST` 选择本机已分配的地址；不能选择普通网卡或0.0.0.0。虚拟IP变更后需要重新启动分享服务并核对防火墙规则。

## 朋友如何访问

1. 朋友安装并运行 ZeroTier One，加入与你相同的网络。
2. 由网络管理员在 ZeroTier Central 授权朋友的设备。
3. 你启动分享服务，保持电脑、ZeroTier和网站服务运行。
4. 将启动窗口显示的 HTTP 地址发送给朋友，例如 `http://你的ZeroTierIP:3180`。
5. 朋友用浏览器打开，注册自己的用户名和密码。每个账号首次使用为空，后续自动保存在这台服务器的独立账号目录；其他设备登录同一账号可读取。无需GitHub账号，不要导入其他人的备份。

当前是虚拟网络内访问地址，不是公网网址。账号记录未额外加密，服务器主人可以管理服务器文件；请使用单独密码并定期导出备份。当前HTTP只用于可信私有网络，不用于公网。旧浏览器记录迁移见 [LOGIN.md](LOGIN.md)。

当前电脑可用 `E:\ZeroTier One\start.cmd` 启动并选择1，或运行项目分享脚本；两者均读取server-location.json中的sharePort，当前为3000。无配置时项目分享脚本默认3180。请以实际启动窗口中的地址为准。

## 防火墙规则（需明确批准和Windows管理员权限）

`Enable-ZeroTier-Sharing.ps1` 只创建或更新名称为 `TianQing-ZeroTier-Web-3180` 的入站允许规则：

- 仅 TCP 3180；
- 仅所选 ZeroTier 本机IPv4和网卡；
- 来源限制为该虚拟网卡的IPv4子网；
- 程序限制为本机 node.exe；
- 不关闭防火墙，不开放3177本机日记端口。

规则会持久保留，直到主动禁用或删除。本次尚未获得此具体防火墙设置的批准，因此未执行脚本。
管理员可使用 `Disable-NetFirewallRule -Name TianQing-ZeroTier-Web-3180` 关闭此规则。

分享服务提供网页和注册登录后的账号API。自动测试确认 `/api/local-records`、`/api/data`、原本机日记文件、账号目录、日志和仓库文件均不可通过静态路径访问，不提供本机会话令牌。账号验证、备份位置和迁移步骤见 [LOGIN.md](LOGIN.md)。

## 检查

`npm test` 包括分享模式的数据隔离和监听地址限制测试。本机访问返回200，只能证明本机服务已启动；朋友端连通仍需要其设备入网、获授权并通过双方网络及防火墙。

官方说明：https://docs.zerotier.com/website/

## 启动状态面板与检查

分享启动窗口显示版本、Node.js、网页资源、账号模块、ZeroTier网卡和实际访问地址。只绑定ZeroTier网卡时，“本机打开”和“朋友访问”使用同一个虚拟IP地址，不显示未监听的localhost或普通网卡网址。检测到已有心晴账号服务时显示“已在运行”，不会额外启动一个服务；重复双击也会保留状态窗口，便于核对地址。关闭这个复用窗口不会关闭原服务，需在原服务窗口停止。

当前电脑的 `E:\ZeroTier One\start.cmd` 默认3000端口，同目录 `doctor.cmd` 提供只读环境与服务连通检查。项目里运行 `npm run doctor` 共用本机端口配置（当前3000，无配置时3180，也可用TIANQING_SHARE_PORT覆盖），与项目分享入口一致。在服务器目录运行 `npm run status` 可检查全部三个项目。诊断不会修改防火墙、账号或记录，也不能证明朋友端能连通；出现问题时应核对双方入网授权和朋友端的实际报错。

## 本机数据目录

当前电脑通过 `server-location.json` 及ZeroTier入口固定使用 `E:\ZeroTier One`。账号、原本机记录、运行日志、临时文件和迁移备份分别位于data/accounts、data/desktop、logs、temp、backups。数据不放进public，不对朋友公开目录，也不再自动存入C盘用户目录；位置配置已被Git忽略。启动窗口显示实际账号目录，doctor检查保存位置是否与运行中的服务一致。
