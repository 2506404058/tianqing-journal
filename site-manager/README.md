# 站点管家 · 本机网站管理中心

独立的 Node.js 管理网站，无运行依赖、CDN或外部账号服务。默认只监听 **127.0.0.1:3190**，访问 `http://localhost:3190`，不对局域网或ZeroTier开放，不修改防火墙。

## 使用

1. 双击 `E:\ZeroTier One\启动网站管理中心.cmd`。服务启动后会打开浏览器；已有服务时复用。
2. 首次打开，由本机主人设置独立的管理员用户名与密码（至少12个字符）。没有默认密码，不使用心晴普通用户账号。
3. “管理概览”查看已接入网站、用户数量与记录文件体积。“网站与用户”选择网站后搜索、筛选用户，查看资料、心情、日程与照片。
4. 可停用或恢复用户、强制退出所有设备、导出兼容心晴的完整JSON记录、备份网站账号和记录文件。停用及强制下线会使普通和30天自动登录立即失效；恢复账号后须重新登录，原记录保留。
5. “操作记录”显示最近100条审计。“管理设置”可修改管理员密码。管理员会话最长8小时、空闲1小时后失效，服务重启后须重新登录。

后台停用功能要求心晴版本支持 `disabled` 和 `authVersion` 检查，本次已同步接入。旧账号缺少这些字段时按正常账号、会话版本0处理，没有批量改写用户文件。

## 接入更多网站

- **心晴兼容账号结构**：填写网站名称、私网/本机根网址、服务器根目录内的账号绝对路径（包含 `users`、`records`）。可使用用户管理、备份和服务检查。不同网站使用不同账号目录，不合并用户。
- **仅登记入口**：可登记其他http/https网站的访问地址，作为统一入口；不会猜测或自动读取未知数据库，页面明确提示用户管理待接入。
- 其他数据库或接口需要增加专用适配器。当前实现集中在 `adapters/tianqing.js` 和 `lib/sites.js`，界面不允许上传或执行适配器代码。适配器提供用户列表、记录查看、状态更改、会话撤销和备份方法。
- 归档网站仅归档管理接入，保留网站服务和全部用户数据。可编辑接入取消归档恢复。

服务连接检查只访问明确登记的localhost或私网IPv4，不跟随重定向，不向目标网站发送管理员Cookie；普通链接型网站只登记入口，不由后台抓取远程内容。

## 文件位置

```text
E:\ZeroTier One\
  site-manager\                  管理中心程序（web为唯一公开资源目录）
  data\manager\admin.json        管理员密码哈希，不能上传或分享
  data\manager\sites.json        网站接入登记
  data\accounts\                 心晴账号数据，保持原位置
  backups\manager\user-changes\  管理操作前的账号原件备份
  backups\manager\sites\         网站完整备份及SHA-256清单
  logs\manager-audit.jsonl        审计日志，最多约5MB并保留上一份
  logs\manager-runtime.jsonl      启动/错误日志
  temp\、cache\                  临时文件和启动缓存
```

网站备份逐文件保存账号、记录及上一版记录备份，附带文件哈希；**排除sessions登录凭证**。在线备份不是跨文件事务快照，需要严格同一时刻的整站备份时，应先暂停对应网站写入。备份中包含密码哈希和私人记录，保留在E盘，不通过静态网址公开。暂不提供覆盖式一键恢复或永久清空用户数据。

日志记录谁在何时查看或更改哪个账号、导出或备份哪个网站，不记录日记正文、明文密码、密码哈希或Cookie。管理员能够读取已接入网站的私人记录，管理员密码应独立保存。没有邮箱/短信找回服务。

## 权限与校验

管理员认证与普通网站用户认证完全独立，使用单独Cookie。每条管理接口都验证管理员会话，写入另验精确Origin、自定义请求头、CSRF；登录限流，密码使用随机盐和scrypt（N=2^17，r=8，p=1）。接口只返回白名单资料字段，不返回密码哈希。路径接入检查真实路径，拒绝越界符号链接；静态文件只提供明确的三项页面资源，不提供任意文件浏览。

设计参考：[OWASP授权指引](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)。

`npm test` 使用临时虚拟用户，验证认证隔离、跨站/CSRF、目录限制、数据导出、管理修改、完整备份、审计与会话失效，不操作真实用户。心晴原项目另有完整回归测试。

联合启动：双击 E:\ZeroTier One\start.cmd（或在该目录运行 npm start），输入3启动管理中心、4启动全部项目。菜单包含心晴、开黑聊天室和管理中心。已有服务会复用；输入0或Ctrl+C只停止本窗口创建的服务。独立的启动网站管理中心.cmd仍可使用。
