# 心晴与同频 · 私人网站套件

三个无第三方运行依赖的 Node.js 项目，共用一个启动菜单：

| 项目 | 目录 | 用途 |
| --- | --- | --- |
| 心晴手账 | `心晴手账/` | 心情、日程、日历与个人记录 |
| 同频开黑聊天室 | `开黑聊天室/` | 文字聊天、WebRTC语音与小队房间 |
| 网站管理中心 | `site-manager/` | 本机管理网站入口及心晴账号 |

## 启动

安装 Node.js 20 或更新版本，在 Windows 双击根目录 `start.cmd`，或运行 `npm start`。无需 `npm install`。菜单支持单独启动、一键启动、检查状态和停止本窗口启动的项目。

心晴和聊天室默认使用本机 ZeroTier IPv4。两台设备需加入同一私有网络并获授权。网站管理中心仅监听本机回环地址，不向 ZeroTier 开放。

新检出的套件默认心晴端口为3000、聊天室3443、管理中心3190。可以在 `心晴手账/server-location.json` 中配置本机保存位置和心晴端口，或使用 `TIANQING_SERVER_HOME`、`TIANQING_SHARE_PORT`、`TIANQING_SITE_DIR` 等环境变量。该配置文件不上传；通过总启动器启动时，数据默认保存在套件根目录。

聊天室需要可信的 HTTPS 证书。参见 [聊天室说明](开黑聊天室/使用说明.md)，在本机生成证书并向朋友安全分发公钥证书；私钥不能分享或提交。

## 共用账号

心晴和聊天室使用同一个 `data/accounts` 账号目录。同一个用户名、密码和昵称可用于两个网站，在任一网站注册都不需要在另一网站重新注册。两站分别保持登录状态；管理员停用、强制下线与心晴修改密码会使旧会话失效。聊天室不提供手账记录读取接口。

管理中心使用单独的管理员账号。具体权限与备份说明见 [管理中心说明](site-manager/README.md)。

## 源码与本机内容分离

仓库只包含程序、测试、文档和发布工作流。本机生成的账号、密码哈希、登录凭证、日记、图片、用户上传文件、证书、日志、备份、缓存与机器配置均不提交。

```text
项目根目录/
  launcher.cjs          总启动器
  start.cmd
  心晴手账/            心晴源码
  开黑聊天室/          聊天室源码
  site-manager/         管理中心源码
  scripts/              检查与测试
  data/                 本机数据，Git忽略
  logs/ backups/        本机日志与备份，Git忽略
```

克隆仓库不会带回服务器用户和记录。需要迁移运行数据时，应另行制作私密备份，不能通过公开Git仓库传输。

## 验证与发布

- `npm test`：检查待上传文件并运行三个项目及总启动器的测试。
- `npm run check:privacy`：检查Git索引中的文件范围和常见秘密格式。
- `npm run status`：只读查看本机三个服务状态。
- GitHub Actions 在推送后运行测试。手动运行 `Publish website` 工作流时，仅发布 `心晴手账/public` 静态网页，聊天室和管理中心需要本机Node.js服务，不能由GitHub Pages运行。

`.gitignore` 不会清除已经提交的历史，也不会过滤手工上传的压缩包；请始终检查实际待提交清单，不要使用强制添加来绕过忽略规则。
